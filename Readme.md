# 📊 Customer Churn Analysis | Power BI

## 📌 Project Overview
This project focuses on analyzing customer churn in a telecommunications business using Microsoft Power BI. The interactive dashboard provides insights into customer retention, churn patterns, contract types, tenure, and monthly charges to support data-driven business decisions.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query – Data Cleaning and Transformation
- DAX – Calculated Measures and KPI Development
- Data Modeling
- Data Visualization

## 📈 Dashboard Features
- KPI Cards – Total Customers, Churned Customers, and Churn Rate.
- Donut Chart – Customer distribution by churn status.
- Bar Chart – Churn analysis by contract type.
- Treemap – Customer analysis by risk type.
- Column Charts – Monthly charges and online security analysis.
- Line Chart – Customer type and monthly charges analysis.
- Interactive Visualizations – Dynamic filtering and data exploration.

## 🎯 Project Objectives
- Analyze customer churn and retention patterns.
- Identify customer segments associated with churn.
- Evaluate the relationship between contract types and churn.
- Compare monthly charges for churned and retained customers.
- Track key performance indicators using an interactive dashboard.

## 💡 Key Analytical Areas
- Customer Churn Rate
- Customer Retention
- Contract Type Analysis
- Customer Tenure Analysis
- Monthly Charges Comparison
- Customer Risk Segmentation
